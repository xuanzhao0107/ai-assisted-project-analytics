# Cross River Rail – Excel Project Analytics

## Overview

This stage applies Excel to analyse selected publicly available data from the Cross River Rail (CRR) project in Queensland, Australia.

The objective is to develop practical Excel skills while learning how project data can support PMO and project management decision-making.

## What I Have Analysed

### 1. Source Register

A structured source register was created to track where project data comes from.

This improves data traceability by recording:

- Source ID
- Organisation
- Publication period
- Official source
- Project management area
- Reliability
- Extraction priority

### 2. Project Cost Timeline

Historical project cost estimates and expected operational years were compared across reporting periods.

The analysis currently includes:

- Estimated project cost
- Cost increase between reporting periods
- Cost growth percentage
- Schedule slippage
- Source references

### 3. Cost Trend Analysis

A line chart was created to show how the estimated project cost changed across the observed reporting periods.

The selected data indicates a substantial increase in project cost over time.

### 4. Schedule Slippage Analysis

Expected operational dates were compared between reporting periods to identify changes in the project delivery timeline.

### 5. Major Work Package Analysis

Three major Cross River Rail work packages were analysed:

- Tunnel, Stations and Development (TSD)
- Rail, Integration and Systems (RIS)
- European Train Control System (ETCS)

The analysis compares:

- Estimated package cost
- Cost share
- Cost ranking
- Delivery model
- Delivery partner

## Current Management Insights

- Estimated project cost increased materially across the observed reporting periods.
- The largest cost increase in the current dataset occurred between 2023 and 2024.
- The expected operational year shifted from 2024 to 2029.
- TSD is the largest of the three major work packages analysed.

## Data Quality Note

The 2024 cost figure was reported as greater than AUD 17 billion.

A value of AUD 17.0 billion was used only as a conservative reference point for calculation and visualisation and should not be interpreted as an exact official estimate.

## AI-Assisted Workflow

AI was used to support:

- project discovery;
- source identification;
- source comparison;
- analytical planning;
- Excel learning.

AI-generated suggestions were not treated as verified facts.

Official sources were checked before data was used, and unsupported AI-generated fields were rejected or revised.

The workflow follows:

**AI Research → Human Verification → Structured Data → Excel Analysis → Management Insights**
